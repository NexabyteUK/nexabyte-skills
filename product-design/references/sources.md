# Sources: where to go deeper

The original guidance behind this skill, by topic. Use it to check a specific point, to read the full reasoning, or when a platform detail matters and may have changed. Platform guidance moves yearly, so for anything version-specific (iOS, Android, Expo), check the source rather than relying on memory. All links were checked in October 2026.

Apple's HIG pages are rendered with JavaScript. If a fetch returns only a title, the same content is available as JSON at `https://developer.apple.com/tutorials/data/design/human-interface-guidelines/<page>.json`.
